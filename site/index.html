Getting Started

Up and Running
in Sixty Seconds

View GitHub Repo
1

Clone & Build Daemon

Compile the high-speed Axum daemon with SQLite embedded storage.

git clone https://github.com/whysooraj/besynx.git
2

Run the Local Service

Start the local background process listening exclusively on loopback.

cargo run -p daemon --release
3

Load WebExtension

Add the extension to Chrome, Arc, or Firefox to start indexing tabs.

# Load folder: besynx/extension
