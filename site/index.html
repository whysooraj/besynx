Zero Configuration Friction

Up and running in sixty seconds.

No signups, no authentication emails, no passwords. Just run the single compiled binary and load the extension in your preferred browsers.

1

Run the local daemon

The lightweight Rust daemon initializes your encrypted SQLite database and starts listening on 127.0.0.1 with locked file permissions.

cargo install besynx
2

Add the WebExtension

Install the BeSynx extension in Chrome, Firefox, Arc, or Zen. It connects to your daemon using an ephemeral local authorization token.

Chrome Web Store · Firefox Add-ons
3

Pair your machines once

Exchange Ed25519 identity keys between your laptop and desktop. Once paired, they discover each other on LAN and sync seamlessly in the background.

besynx pair --peer 192.168.1.45
Technical Integrity

Local-first engineering you can verify.

Unlike cloud synchronization services that monetize your telemetry or risk credential leaks, BeSynx is open-source software that honors your disk as the source of truth.

  • Offline-First Event Queue: History events are queued in chrome.storage.local if the daemon is stopped, draining cleanly upon reconnection.
  • Cryptographic Identity: Mutual Ed25519 signature verification prevents rogue devices on guest Wi-Fi from injecting or reading history.
  • Anti-Hijacking Guards: Strict Origin header validation and CSWSH mitigation tokens protect local WebSockets from malicious webpage scripts.

Clear Answers

Frequently asked questions.

Honest technical clarity on how BeSynx handles your browser data.

Does any of my data ever leave my home network?

No. BeSynx has zero remote servers, zero analytical telemetry, and zero third-party endpoints. Communication happens exclusively over your local Wi-Fi or LAN between paired daemon instances.

Which browsers can I synchronize between?

Any browser supporting Manifest V3 WebExtensions: Google Chrome, Mozilla Firefox, Brave, Arc, Zen Browser, and Microsoft Edge. You can mix and match different engines freely.

What happens if my laptop is away from home?

The browser extension buffers every visit into an indexed offline queue. The instant your laptop reconnects to your local daemon or home network, the queue drains automatically without losing a single tab.

How does cookie synchronization work safely?

BeSynx synchronizes domain cookies with built-in reflection prevention and domain boundary checks, preserving active login sessions without creating infinite loops between paired browsers.
