Technical Architecture

Local-first privacy, by design

Traditional sync solutions route every URL you visit through corporate telemetry clouds. BeSynx isolates all browser session indexing inside a local Rust daemon.

Local Engine

Rust Axum Daemon

Runs as a lightweight native background process on `127.0.0.1:9098`. Indexes tab history and open sessions into an embedded SQLite database.

Storage

Embedded SQLite Store

Zero external database server needed. High-speed local full-text search across all opened tabs and historical visits with zero network latency.

Extension Bridge

Manifest V3 Native Bridge

Cross-browser WebExtension communicates directly with the local daemon via authenticated REST calls and native messaging hooks.

Interoperability

One unified sync layer across all browsers

Break out of proprietary sync silos. Mix and match your preferred browser on every machine.

Getting Started

Up and running in three steps

Deploy BeSynx locally using Rust toolchain and standard browser developer extension loading.

01

Build and run the local daemon

Compile the Axum HTTP backend and SQLite persistence service.

git clone https://github.com/sooraj-makala/besynx.git && cd besynx && cargo run -p daemon --release
02

Load the browser extension

Load the unpacked extension/ folder in Chrome (chrome://extensions) or Firefox (about:debugging).

# Load directory: besynx/extension
03

Verify local synchronization

Check daemon health and active registered tab streams on loopback.

curl http://127.0.0.1:9098/health
